Pangea’s People | What If Europe Never Existed

About the Project

Pangea’s People | What If Europe Never Existed is an application developed by Marlon Barrios Solano, blending concept, programming, generative AI, sound design, and performance. It explores the speculative scenario of human cultures and identities developing independently, untouched by European historical influence.

Composition

The project integrates several elements:
	•	Software Development: Real-time text-to-image generative AI performance as a live app that runs in the browser.
	•	Soundscape: Created with the AI tool Musicgen.
	•	Interactive Drawing Tool: Allowing performers and users to engage visually.
	•	Immersive Soundtrack: Specifically composed for the app experience.

Latent space refers to a conceptual mathematical space used by generative AI models, characterized by high-dimensional data representation. In latent spaces, similar data points cluster closely, while dissimilar points spread apart, allowing models to generate new, plausible data based on learned patterns.

Performing in latent space involves improvisational interaction with AI models, creating unpredictable and unique art performances. Users guide generative processes through prompts, dancing metaphorically within this probability-driven creative space.

“Pangea’s People” invites audiences to reimagine global history by visualizing diverse, speculative human cultures and societies in a reality where Europe never influenced global dynamics. This alternative scenario fosters dialogue around identity, diversity, and historical imagination.

Getting Started

Follow these steps to use the app:

Prerequisites
	•	Node.js for running the application and managing dependencies.

Installation
	1.	Clone the Repository

git clone [repository-link]

or download the zip file

	2.	Install Dependencies

cd <project-directory>
npm install

	3.	Configure Environment

Rename .env.local.example to .env.local and enter your Fal.ai API Key from Fal.ai Dashboard.

# .env.local example
FAL_AI_API_KEY=your_api_key_here

	4.	Run the Application

npm run dev

Access http://localhost:3000 in your browser.
